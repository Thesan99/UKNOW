# UKNOW 🔍

UKNOW is a free tool that analyses a suspicious image and reports how likely it was generated by AI. Its scope is deliberately narrow: it does not judge whether a claim or news story is true — only whether a file carries measurable statistical evidence of AI generation.

This repo is the **Chrome**: right-click any image on a page and UKNOW sends it to the detector and shows a panel with a real-vs-AI score, a Grad-CAM heatmap, and short guidance.

## Install (developer / unpacked)

Not yet on the Chrome Web Store — load it manually:

1. Download or clone this repo.
2. Chrome / Edge: open `chrome://extensions`, turn on **Developer mode** (top right).
3. Click **Load unpacked** and select this folder.
4. Right-click any image → **UKNOW 🔍**.

Firefox: open `about:debugging` → This Firefox → **Load Temporary Add-on** → pick `manifest.json`.

## Configuration

The extension talks to a UKNOW detector server (a Hugging Face Space). The URL is set at the top of `background.js`:

```js
const SERVER_URL = "https://thesan99-uknow.hf.space";
```

Change it if you host the detector elsewhere. The Space must be awake for a request to succeed — free Spaces sleep when idle, so the first call may take a few seconds to wake it.

## Server response contract

The extension sends `POST /analyze` (multipart image upload) and expects JSON back with these fields:

| Field | Type | Used for |
|---|---|---|
| `score` | number 0–100 | real score + progress-bar width and colour |
| `band` | string | verdict headline |
| `emoji` | string | icon before the band |
| `heatmap_png_base64` | string | Grad-CAM overlay image |
| `advice` | string | guidance line |
| `explanation` | string | where the marked regions are |

If any field is renamed on the server, the panel breaks silently. Keep this in sync with the Space's `app.py`.
